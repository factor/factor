## Reproduction

The exact upstream shared library used here is an unmodified tag 6.0 checkout:

```sh
git clone --depth 1 --branch 6.0 https://github.com/raysan5/raylib.git /tmp/factor-raylib-varargs-6.0
make -C /tmp/factor-raylib-varargs-6.0/src RAYLIB_LIBTYPE=SHARED -j4
sh reference/raylib-6-completion-20260908/build.sh
```

Run the verified ARM64 VM against an image containing the ARM64 ABI work and
this checkout as resource root. The environment must expose the library before
loading Raylib: changing its registration afterward leaves already compiled
words referring to their original unresolved DLL object.

```sh
DYLD_LIBRARY_PATH=/tmp/factor-raylib-varargs-6.0/src \
RAYLIB_API60_FONT=/tmp/factor-raylib-varargs-6.0/examples/text/resources/anonymous_pro_bold.ttf \
/path/to/Factor.app/Contents/MacOS/factor -i=/path/to/final.image \
  -resource-path="$PWD" -no-user-init -no-monitors \
  reference/raylib-6-completion-20260908/run.factor
```

The recorded VM is `/Users/erg/factor.worktrees/arm64-varargs-entry/Factor.app/Contents/MacOS/factor`;
image `/Users/erg/factor/reference/arm64-varargs-20260908/final.image`.
Use `docs.factor` in place of `run.factor` to validate help loading.

the old binding for the baseline harness, then reapply it afterward. The harness

