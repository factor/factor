# Execution-rate and static-code diagnostics

Runtime totals describe execution-rate context, not equally weighted workload rankings. Static counts are sums across twelve separately compiled kernels. Spills, reloads and copies count final machine-IR opcodes, not dynamic events or emitted machine instructions. Equal-register copies can emit no instruction; code-bytes measures actual generated bytes.
